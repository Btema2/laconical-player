How should library content exit?

When search opens, the track list / albums grid below the top bar fades away. Which exit feels better?

1

Pure fade

Opacity 1 → 0. Clean, minimal. Content just disappears.

2

Fade + scale down REC

Opacity 1 → 0 while scale 1.0 → 0.96. Feels like content recedes into the background. Adds depth without being dramatic.
